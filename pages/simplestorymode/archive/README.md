# Archive — NOT POSTABLE

These files are the old "Wisdom" quote bank from stage 1 (367 original reflections and 81
verified public-domain quotes). The owner decided on 2026-10-18 that **none of them may be
posted** on Simple Story Mode.

Nothing in the publishing pipeline reads this folder: Simple Story Mode posts come only from
owner-approved items in `../queue/`. The files are kept for reference and as test data for the
quote-bank engine (selection, near-duplicate checks), which future pages may reuse.

- `content.json` — the built bank (every entry's `status` is `archived`).
- `sources/` — `originals.txt`, `public_domain.yaml` (verify with `scripts/verify_pd_quotes.py`),
  `synonyms.yaml`.
- `captions-quotes.json`, `theme-quotes.yaml` — the old caption kit and 8 visual templates.
